# Student Academic Portal

A sleek, responsive academic web portal developed for the Java / Full Stack Java Programming (FSJP) coursework.

## 📌 Details
- **Institution:** A. P. Shah Institute of Technology
- **Department:** Information Technology (SE, Div A)
- **Student:** Parth Deshmukh 

## 🛠️ Tech Stack
- HTML5 (Semantic Structure)
- CSS3 (Custom Flexbox, Grid & Theme Styling)
- Bootstrap 5

## 🚀 Key Features
- **Student Profile:** Details, technical skills, and hobbies.
- **Academic Performance:** Structured semester performance table.
- **Support Interface:** Modern query and feedback form.
- Fully responsive and screenshot-optimized design.
